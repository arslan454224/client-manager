# Client Manager

Консольная CRM на Python для управления клиентами и их заявками. Программа позволяет вести клиентскую базу, работать со статусами, выполнять поиск и сохранять данные между запусками.

## Возможности

- добавление клиентов;
- защита от повторного номера телефона;
- поиск клиента по имени, части имени или номеру;
- просмотр и фильтрация клиентов;
- изменение статуса клиента;
- создание заявок для существующих клиентов;
- поиск заявки по ID;
- изменение статуса и удаление заявки;
- фильтрация заявок по статусу;
- сохранение клиентов и заявок в JSON;
- экспорт клиентов в CSV;
- обработка неправильного пользовательского ввода.

## Структура проекта

- `app/main.py` — консольное меню и обработчики команд;
- `app/clients.py` — бизнес-логика работы с клиентами;
- `app/applications.py` — бизнес-логика работы с заявками;
- `app/storage.py` — загрузка и сохранение JSON, экспорт CSV;
- `app/config.py` — загрузка настроек из переменных окружения;
- `.env.example` — пример необходимых переменных окружения;
- `requirements.txt` — зависимости проекта.

## Установка

Склонируйте репозиторий:

```powershell
git clone https://github.com/arslan454224/client-manager.git
cd client-manager
```

Создайте виртуальное окружение:

```powershell
python -m venv .venv
```

Активируйте его:

```powershell
.venv\Scripts\Activate.ps1
```

Установите зависимости:

```powershell
python -m pip install -r requirements.txt
```

## Настройка

Создайте файл `.env` на основе `.env.example`:

```powershell
Copy-Item .env.example .env
```

Укажите в `.env` значение секретного ключа:

```text
APP_SECRET_KEY=your-secret-key
```

Файл `.env` добавлен в `.gitignore` и не должен попадать в Git.

## Запуск

Запустите программу из корневой папки проекта:

```powershell
python -m app.main
```

## Хранение данных

При работе программы автоматически создаётся папка `data`.

- `data/clients.json` — клиенты;
- `data/applications.json` — заявки;
- `data/clients.csv` — экспортированный список клиентов.
- `data/applications.csv` — экспортированный список заявок.

JSON-файлы сохраняют данные между запусками программы.
